# Лабораторная работа 1. Подготовка окружения и работа с СУБД SQLite

## Описание проекта
В данном каталоге находится развернутое окружение для выполнения заданий лабораторной работы, включающее исходный набор данных (датасет) и результаты первичного анализа данных с помощью утилит командной строки и СУБД SQLite.

## Структура файлов исходных данных (датасет)
* **movies.csv** (movieId, title, genres) — каталог фильмов с указанием их жанров.
* **ratings.csv** (userId, movieId, rating, timestamp) — оценки, выставленные фильмотеке пользователями.
* **tags.csv** (userId, movieId, tag, timestamp) — текстовые теги, присвоенные фильмам.
* **users.txt** (id, имя, email, пол, дата, профессия) — профили пользователей с разделителем `|`.
* **genres.txt** — справочник доступных жанров.
* **occupation.txt** — справочник зафиксированных профессий.

## Выходные файлы и отчеты
* **ratings_count.txt** — отчет, содержащий минимальный и максимальный идентификаторы пользователей из файла `ratings.csv`, а также точное количество строк (оценок) для каждого из них.
* **sqlite.txt** — лог с номером установленной версии SQLite на локальной машине и списком всех доступных режимов вывода данных (output modes) утилиты `sqlite3`.
